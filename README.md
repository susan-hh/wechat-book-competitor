# 短视频带货竞品分析系统 · 分享版

一个**纯本地**的 HTML 工具，用于跟踪视频号上图书带货竞品：记录哪些账号在卖、每天卖了多少、哪些视频成了爆款，并自动算出增长趋势与销量排名。数据全部存在你自己的浏览器里，不上传任何服务器。

> ⚠️ **数据独立声明**：本分享版数据完全本地存储，不与任何主版本/原作者互通、不同步。你录入的竞品数据只存在你自己的浏览器里。

## 文件
- `竞品分析工具_分享版_空模板.html` —— 主程序，双击用 Chrome / Edge 打开
- `data.js` —— 初始示例数据（含一个示例账号「六月人物漫谈」），**必须与 html 同目录**
- `使用说明.md` —— 完整使用说明（含给 WorkBuddy 的「工具说明书」）

> ⚠️ html 与 data.js 必须放在同一文件夹；只拷 html 单独打开会是空白。

## 从 GitHub 下载后怎么用
1. 下载整个仓库（绿色「Code」按钮 → Download ZIP），解压到任意位置。
2. 双击 `竞品分析工具_分享版_空模板.html`，用 Chrome / Edge 打开。
3. 默认会显示一条示例账号「六月人物漫谈」，看清格式后点「清空本地数据」即可开始你自己的记录。
4. 不需要安装任何东西、不需要起服务器、不需要联网。

## 用 WorkBuddy 一句话安装
在 WorkBuddy 里说：
> 装一下「短视频带货竞品分析系统」分享版，从 GitHub 仓库 `susan-hh/wechat-book-competitor` 拉到本地 `<你的目录>`，并按 `使用说明.md` 认识这个工具。

WorkBuddy 会拉取文件、校验同目录、阅读使用说明，之后就能帮你整理 / 导入竞品数据。

> ⚠️ 如果让 WorkBuddy 直接帮你写 `data.js`，它只应写**本分享版目录下**的 data.js（与 html 同目录的那个），不要碰任何"主版/主目录"的 data.js——两者数据独立、不同步。

## 日常用法速览
1. 点「导出采集清单」复制所有账号的微信小店链接 → 微信里点开看销量；
2. 点「批量新增记录」粘贴 `账号名（领域 / 商品） 当前销量`，解析预览后确认写入；
3. 看「数据看板」的增长榜 / 趋势 / 商品排名；增长榜每行有「复制地址」可复制橱窗链接。

完整说明见 `使用说明.md`。
